BINA for Autodesk Revit

BINA lets you upload Revit models from inside Revit directly to BINA Cloud (BIMCloudX), with no manual export step. This help page covers installation, sign-in, uploading, and troubleshooting.

What it does

  • Adds a BINA ribbon tab to Revit with three commands: Upload to BINA, Project Settings, and Sign In / Account.
  • Uploads the active Revit document to BINA Cloud, tagging it with a discipline (Architecture, Structure, HVAC, Electrical, or general MainFile).
  • Optionally registers the model with Autodesk's viewer service so collaborators can preview it in the browser.

Prerequisites

  • Autodesk Revit 2025, 2026, or 2027 (64-bit Windows).
  • A BINA Cloud account. Don't have one? Visit https://bina.cloud to sign up.
  • An internet connection to reach BINA Cloud during sign-in and upload.

Signing in

  1. Open Revit and go to the BINA ribbon tab.
  2. Click Sign In / Account.
  3. Enter your BINA Cloud email and password.
  4. Choose the project you want to upload to. You can change this later from Project Settings.
Your password is never stored on disk. A short-lived access token lives only in memory; a refresh token (if your account uses one) is encrypted with Windows DPAPI before being saved.

Uploading a model

  1. Open the Revit project you want to upload and save it.
  2. Click Upload to BINA on the BINA ribbon.
  3. If you haven't set a default discipline, choose one when prompted (Architecture, Structure, HVAC, Electrical, or MainFile).
  4. Wait for the upload to complete. A results window shows the status of each destination (BINA storage, Autodesk viewer, registration).
Save the Revit document before uploading. Uploading an unsaved file is not supported, because BINA needs a real path on disk to read the model.

Project settings

From Project Settings you can:

  • Switch the active project. Pick a different BINA Cloud project to upload to. The connector uploads to one project at a time.
  • Set a default discipline. If you usually upload the same discipline (e.g. Architecture), set it here and the connector will skip the discipline prompt every time.
  • Confirm before uploading. When enabled, the connector asks "Upload file to project?" before starting the upload. Useful as a final safety check on large projects.

Troubleshooting

"Could not reach BINA Cloud"

Check your internet connection. If you're on a corporate network, confirm that your firewall allows outbound HTTPS to BINA Cloud and to developer.api.autodesk.com. Then click Upload again.

"Please sign in"

Your session expired (sessions don't survive a Revit restart yet). Click Sign In / Account and re-enter your password.

"Please save your Revit file before uploading"

Use Ctrl+S in Revit to save the document, then click Upload again.

Upload partially succeeded

The results window shows three statuses: BINA storage, Autodesk viewer, and registration. If only the Autodesk viewer step failed, the file is still safely in BINA Cloud and your team can download it; only the in-browser preview will be unavailable until you re-upload.

Where are the logs?

Detailed logs are written to %APPDATA%\BINA\BinaConnector\logs\. Send these to support if you report a bug.
